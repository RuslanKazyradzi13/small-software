# Изменения

## 0.3.0 — 2026-10-10

### Добавлено
- **`small env`** — `list` / `set KEY=VALUE` / `unset KEY`. Переменные меняются сразу в Railway и в `small.json`,
  затем приложение один раз перезапускается (`--no-deploy` — без перезапуска). В списке видно, где задана
  переменная: в обоих местах, только в Railway или значения расходятся. Значения скрыты, `--values` их показывает.
- **`small access`** — токен на каждого человека: `add ИМЯ` выдаёт личную ссылку, `revoke ИМЯ` отзывает только её,
  `list` показывает, у кого есть доступ. `small link --as ИМЯ` / `small open --as ИМЯ` дают личную ссылку.
  `ACCESS_TOKEN` теперь понимает формат `alice:токен1,bob:токен2`, совместимый со старым; входы пишутся в лог
  строкой `вход по ссылке (имя)`.
- **Шаблон `fastapi`** — FastAPI + uvicorn; Railway (Railpack) сам запускает `uvicorn main:app`. Токен скрыт
  в access-логе uvicorn.
- **`MagicLinkASGI`** в `magic_link.py` — защита для ASGI (FastAPI, Starlette): HTTP, websocket и lifespan.
- **Дашборд:** кнопки «Открыть по ссылке» (сразу с токеном владельца) и «Логи» (окно с логом приложения или сборки).

### Изменено
- `magic_link.py`: общая логика WSGI и ASGI вынесена в одно ядро. Поведение WSGI не изменилось.
- `small init` в подсказке «Дальше» предлагает `small open`.
- CI: шаблоны `streamlit` и `fastapi` проверяются на настоящих фреймворках; логи Windows-заданий в UTF-8.

## 0.2.0 — 2026-10-10

### Добавлено
- **`small init`** — заготовка приложения из шаблона: `python-http` (по умолчанию), `node-http`, `streamlit`.
  Создаёт сервер с защитой по ссылке-приглашению, `small.json` с уникальным именем и `ACCESS_TOKEN`,
  `.gitignore` и `.railwayignore`. Существующие файлы без подтверждения не перезаписываются.
- **`small.json`** — настройки приложения: `name` (имя проекта и поддомена) и `env` (переменные сервиса, передаются
  в Railway при каждом деплое). Явное имя привязывает папку к одноимённому проекту в Railway, без дубликатов.
- **`small dashboard`** — локальная страница со списком приложений в папке. Если задан `RAILWAY_API_TOKEN`, показывает
  живой статус последнего деплоя (`SUCCESS`, `BUILDING`, `FAILED`…).
- **`small link` / `small open`** — ссылка-приглашение задеплоенного приложения; `open` открывает её в браузере.
- **`small logs`** — лог приложения или сборки (`--build`), `-n`, режим слежения `-f`.
- **`small destroy`** — удалить приложение из Railway: проект целиком или только свой сервис в общем проекте.
- `small deploy` переименовывает домен в `<name>.up.railway.app`, если такое имя свободно.

### Исправлено
- `small.cmd` выдавал мусорные ошибки «не является командой»: `cmd.exe` неверно разбирал UTF-8 и переводы строк LF.
  Теперь файл только ASCII и с CRLF (в git это закреплено в `.gitattributes`).
- Токен Railway, сохранённый в виде `"<токен>"` (с угловыми скобками из заготовки), ломал все запросы. Теперь
  пробелы, кавычки и угловые скобки по краям токена отбрасываются.

## 0.1.0 — 2026-10-10
