# Изменения

## 0.5.0 — 2026-10-10

### Добавлено
- **Вход по рабочей почте** — как доступ к Google Doc. `small access add ivan@company.com` (или `@company.com` —
  весь домен) добавляет адрес в `ACCESS_EMAILS`. Человек открывает приложение, вводит почту и получает письмо со
  ссылкой для входа: 15 минут, один раз, вход по кнопке «Войти» (почтовые сканеры не «тратят» ссылку); браузер
  помнит вход 30 дней. Пересланная ссылка ничего не даёт: войти может только владелец адреса.
  - Отзыв (`small access revoke ivan@company.com`) закрывает и уже выданную сессию.
  - На любой адрес ответ одинаковый; незнакомый адрес — запрос доступа в лог и Telegram с готовой командой.
  - Ссылки и сессии подписаны `SESSION_SECRET` (создаётся при первом `add`); адрес в письме берётся из
    `PUBLIC_URL`/`RAILWAY_PUBLIC_DOMAIN`, а не из заголовка `Host`; лимит — 3 письма на адрес за 15 минут.
  - Работает в `magic_link.py` (WSGI и ASGI) и `magic-link.js`, то есть в шаблонах `python-http`, `fastapi`,
    `node-http`. Шаблон `streamlit` пока поддерживает только личные ссылки.
- **`small mail resend|smtp|log|off`** — чем отправлять письма для входа. Resend работает по HTTPS и на Railway
  Hobby, где SMTP закрыт; SMTP — свой сервер (на Railway — с тарифа Pro); `log` пишет ссылку в лог для проверки.
  Перед сохранением отправляется пробное письмо тем же кодом, что и в приложении.
- `/_access/logout` — выйти.
- **Английский интерфейс.** Страницы входа и письма — на русском или английском по языку браузера
  (`Accept-Language`); `ACCESS_LANG=ru|en` задаёт язык явно.
- Лицензия MIT, README на английском и русском, CONTRIBUTING, SECURITY, шаблоны issue и PR.

### Изменено
- `small access add` понимает адреса и домены; имена-токены работают как раньше. `small access list` показывает и
  адреса, и имена.
- `small deploy` создаёт домен до загрузки кода. При входе по почте он передаёт приложению `PUBLIC_URL` с настоящим
  доменом: живая проверка показала, что после переименования домена Railway держит в `RAILWAY_PUBLIC_DOMAIN`
  прежний адрес, и ссылки из писем вели на 404.
- Шаблоны `python-http` и `fastapi` прячут в access-логе не только `?token=`, но и `?t=` — одноразовую ссылку для
  входа из письма.

## 0.4.1 — 2026-10-10

### Исправлено
- Вывод в канал или файл (`small logs | Select-String вход`, `small link > link.txt`) на Windows шёл в кодировке
  ANSI (cp1251), а PowerShell читает его в кодировке консоли: кириллица превращалась в мусор, поиск по ней ничего
  не находил. Теперь в канал `small` пишет в кодировке консоли, а заданную `PYTHONIOENCODING` соблюдает, хотя
  `small.cmd` запускает Python с `-I`. В терминал вывод не изменился.
- `small env list` после `small db add` показывал `DATABASE_URL … Railway ≠ small.json`, хотя всё было в порядке:
  Railway отдавал значение с уже подставленной ссылкой. Теперь сравниваются значения как записаны
  (`variables(unrendered: true)`), а `--values` показывает `${{Postgres.DATABASE_URL}}`, а не адрес с паролем базы.
- README: подсказка про журнал входов — `Select-String` вместо `findstr`, который кириллицу не находит.

## 0.4.0 — 2026-10-10

### Добавлено
- **`small sleep on|off`** — режим сна Railway (serverless): без запросов приложение засыпает и не тратит ресурсы.
- **`small db add|list|remove postgres`** — Postgres из шаблона Railway в проекте приложения; приложению передаётся
  `DATABASE_URL` как ссылка `${{Postgres.DATABASE_URL}}`. `small destroy` удаляет базы вместе с приложением.
- **`small domain add|list|remove`** — свой домен: печатает DNS-записи (CNAME и TXT-проверка), показывает состояние
  DNS и сертификата.
- **`small notify telegram|off`** — запросы с кнопки «Запросить доступ» приходят владельцу в Telegram. Команда
  проверяет токен бота, сама находит ID чата и шлёт пробное сообщение. Поддержка — в `magic_link.py`,
  `magic-link.js` и шаблоне `streamlit`.
- **Дашборд:** бейдж «засыпает» и оценка «≈ $X/мес при текущей нагрузке» (средняя нагрузка за неделю из `metrics` ×
  тарифы Railway), общая сумма в сводке.

### Изменено
- `cli.py` разнесён по модулям `small_cli/commands/` (по файлу на команду) и `common.py`; поведение прежнее.
- Удалён `manual-test-app` — он был просто примером вывода `small init`.

## 0.3.0 — 2026-10-10

### Добавлено
- **`small env`** — `list` / `set KEY=VALUE` / `unset KEY`. Переменные меняются сразу в Railway и в `small.json`,
  затем приложение один раз перезапускается (`--no-deploy` — без перезапуска). В списке видно, где задана
  переменная: в обоих местах, только в Railway или значения расходятся. Значения скрыты, `--values` их показывает.
- **`small access`** — токен на каждого человека: `add ИМЯ` выдаёт личную ссылку, `revoke ИМЯ` отзывает только её,
  `list` показывает, у кого есть доступ. `small link --as ИМЯ` / `small open --as ИМЯ` дают личную ссылку.
  `ACCESS_TOKEN` теперь понимает формат `alice:токен1,bob:токен2`, совместимый со старым; входы пишутся в лог
  строкой `вход по ссылке (имя)`.
- **Шаблон `fastapi`** — FastAPI + uvicorn; Railway (Railpack) сам запускает `uvicorn main:app`. Токен скрыт
  в access-логе uvicorn.
- **`MagicLinkASGI`** в `magic_link.py` — защита для ASGI (FastAPI, Starlette): HTTP, websocket и lifespan.
- **Дашборд:** кнопки «Открыть по ссылке» (сразу с токеном владельца) и «Логи» (окно с логом приложения или сборки).

### Изменено
- `magic_link.py`: общая логика WSGI и ASGI вынесена в одно ядро. Поведение WSGI не изменилось.
- `small init` в подсказке «Дальше» предлагает `small open`.
- CI: шаблоны `streamlit` и `fastapi` проверяются на настоящих фреймворках; логи Windows-заданий в UTF-8.

## 0.2.0 — 2026-10-10

### Добавлено
- **`small init`** — заготовка приложения из шаблона: `python-http` (по умолчанию), `node-http`, `streamlit`.
  Создаёт сервер с защитой по ссылке-приглашению, `small.json` с уникальным именем и `ACCESS_TOKEN`,
  `.gitignore` и `.railwayignore`. Существующие файлы без подтверждения не перезаписываются.
- **`small.json`** — настройки приложения: `name` (имя проекта и поддомена) и `env` (переменные сервиса, передаются
  в Railway при каждом деплое). Явное имя привязывает папку к одноимённому проекту в Railway, без дубликатов.
- **`small dashboard`** — локальная страница со списком приложений в папке. Если задан `RAILWAY_API_TOKEN`, показывает
  живой статус последнего деплоя (`SUCCESS`, `BUILDING`, `FAILED`…).
- **`small link` / `small open`** — ссылка-приглашение задеплоенного приложения; `open` открывает её в браузере.
- **`small logs`** — лог приложения или сборки (`--build`), `-n`, режим слежения `-f`.
- **`small destroy`** — удалить приложение из Railway: проект целиком или только свой сервис в общем проекте.
- `small deploy` переименовывает домен в `<name>.up.railway.app`, если такое имя свободно.

### Исправлено
- `small.cmd` выдавал мусорные ошибки «не является командой»: `cmd.exe` неверно разбирал UTF-8 и переводы строк LF.
  Теперь файл только ASCII и с CRLF (в git это закреплено в `.gitattributes`).
- Токен Railway, сохранённый в виде `"<токен>"` (с угловыми скобками из заготовки), ломал все запросы. Теперь
  пробелы, кавычки и угловые скобки по краям токена отбрасываются.
